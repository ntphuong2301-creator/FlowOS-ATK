PHẦN 1 — LOGIC TÍNH % TIẾN ĐỘ
File: server/src/services/tiendo.service.ts
═══════════════════════════════════════════

Viết TiendoService với các hàm sau, tất cả query từ bảng Buoc:

1. tinhTiendoRD(sanPhamId):
   - Lấy tất cả bước mã bắt đầu bằng "RD" thuộc sản phẩm đó
   - % = số bước trangThai=XONG / tổng bước RD × 100
   - Trả về: { phanTram, buocHienTai, tongBuoc, buocXong }

2. tinhTiendoNap(sanPhamId):
   - Lấy tất cả bước mã bắt đầu bằng "NAP"
   - Tổng bước NAP = 13 (cố định)
   - Bước hiện tại = bước NAP có số thứ tự lớn nhất
     đang ở trạng thái XONG hoặc DANG_LAM
   - % = số thứ tự bước hiện tại / 13 × 100
   - Trả về: { phanTram, buocHienTai, tongBuoc: 13 }

3. tinhTiendoBaoBi(sanPhamId):
   - Lấy tất cả bước BBC (chai) + BBNH (nhãn) thuộc sản phẩm
   - % = số bước XONG / tổng bước × 100
   - Trả về: { phanTram, buocXong, tongBuoc,
               chiTiet: { chai, nhan } }

4. tinhTiendoPhapChe(sanPhamId):
   - Bước PCSPB1 đến PCSPB7
   - % = số bước XONG / 7 × 100

5. tinhTiendoSXCN(sanPhamId):
   - Bước SXCN1 đến SXCN6
   - % = số bước XONG / 6 × 100

6. tinhTrangThaiTong(sanPhamId):
   Logic theo thứ tự ưu tiên:
   - Có bước BI_CHAN + cản trở RAT_NGHIEM_TRONG → "🔴 Bị cản trở"
   - Còn < 30 ngày đến launch mà bất kỳ % < 30% → "🔴 Nguy hiểm"
   - Bất kỳ % < 50% → "🟡 Rủi ro"
   - Tất cả % > 80% → "🟢 Chạy mượt"
   - Mặc định → "🟢 Chạy mượt"

7. tinhTongTiendoSanPham(sanPhamId):
   % tổng = trung bình có trọng số:
   R&D 30% + Nắp 25% + Bao bì 20% + Pháp chế 15% + SXCN 10%

GET /api/san-pham/:id/tien-do
Trả về:
{
  sanPhamId, maSP, ten, kenh,
  tongTienDo: number,
  trangThaiTong: string,

    nap:     { phanTram, buocHienTai, tongBuoc: 13 },
    baoBi:   { phanTram, buocXong, tongBuoc },

  },
  canTroHienTai: CanTro[]
}

GET /api/san-pham/tong-quan → summary cho CEO dashboard
