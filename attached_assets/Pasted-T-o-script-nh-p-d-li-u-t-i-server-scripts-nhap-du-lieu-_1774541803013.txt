Dùng thư viện xlsx để đọc file Excel. Cài thêm: npm install xlsx

Đọc file Excel tại:
attached_assets/Quản_lý_dự_án_ra_mắt_sản_phẩm_ATK_(1)_1774540090235.xlsx

Map các sheets:
Sheet "🚩Dự án" → bảng DuAn: "Dự án" → ma+ten, "Nhóm" → nhom, "Trạng thái" → trangThai

Sheet "👣 Các Bước (output)" → bảng Buoc:
  "Tên bước" → ten (giữ nguyên mã: NAP1, DCDB1, RD1...)
  "Dự án" → duAnId (lookup)
  "Định nghĩa hoàn thành" → dinhNghiaHoanThanh
  "Số ngày dự kiến" → soNgayDuKien
  "Incharge" → nguoiPhuTrachId (lookup theo tên)
  "Bắt đầu" → ngayBatDau, "Kết thúc" → ngayKetThuc
  "Trạng thái": "✅Xong rồi"=XONG, "Đang làm"=DANG_LAM,
                "🔴Bị blocked"=BI_CHAN, "Chưa làm"=CHUA_LAM
  "Phụ thuộc vào bước" → tạo PhuThuocBuoc sau khi insert hết bước

Sheet "✅Công việc" → bảng CongViec:
  "Công việc"→ten, "Mục tiêu"→mucTieu, "Dự án"→duAnId
  "Incharge"→nguoiPhuTrachId, "Sprint"→giaiDoanId (lookup)
  "Trạng thái": "Đang làm"=DANG_LAM, "Chưa làm"=CHUA_LAM,
                "Bị cản trở"=BI_CHAN, "Xong rồi"=XONG
  "Ngày bắt đầu"→ngayBatDau, "Ngày kết thúc"→ngayKetThuc
  "Số ngày dự kiến"→soNgayDuKien, "Số ngày trễ"→soNgayTre

Sheet "🔴Cản trở" → bảng CanTro:
  "Hạng mục bị cản trở"→ten, "Dự án"→duAnId
  "Mức độ": "🔴 Rất nghiêm trọng"=RAT_NGHIEM_TRONG,
            "🟡 Vừa phải"=VUA_PHAI, "🟢 Nhẹ"=NHE
  "Trạng thái": "✅Xong rồi"=DA_GIAI_QUYET, "Đang xử lý"=DANG_XU_LY
  "Ai gặp phải"→nguoiGapId, "Ai chịu trách nhiệm"→nguoiXuLyId
  "Ngày phát sinh"→ngayPhatSinh, "Deadline xử lý"→hanXuLy
  "Thông tin thêm..."→moTaGiaiPhap

Sheet "🍶Sản phẩm" → bảng SanPham:
  "Mã sản phẩm"→maSp, "Tên sản phẩm 1"→ten, "Kênh"→kenh
  "Hương vị"→huongVi, "Dung tích"→dungTichMl
  "pH +-0.5"→phLevel, "Ngày launch"→ngayLaunch

Sheet "⏰Sprint" → bảng GiaiDoan:
  "Tên sprint"→ten, "Ngày bắt đầu"→ngayBatDau
  "Ngày kết thúc"→ngayKetThuc, "Tiến độ sprint"→tienDo
