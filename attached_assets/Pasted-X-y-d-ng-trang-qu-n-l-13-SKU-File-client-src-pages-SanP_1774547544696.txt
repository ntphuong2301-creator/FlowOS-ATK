PANEL CHI TIẾT — mở khi click vào thẻ
═══════════════════════════════════════════

Panel trượt từ phải (width 420px):

1. Header: tên SP + badge kênh + trạng thái tổng

2. % chi tiết từng bước:
   Mỗi dòng: tên bước · trạng thái · ngày KT
   Nhóm theo: R&D / Nắp / Bao bì / Pháp chế / SXCN
   Bước XONG → màu xanh + icon ✓
   Bước DANG_LAM → màu xanh dương + icon ⟳
   Bước BI_CHAN → màu đỏ + icon ⚠
   Bước CHUA_LAM → màu xám

3. Cản trở đang mở của SP này:
   - Tên cản trở + mức độ + người xử lý + hạn

4. AI gợi ý "Bước tiếp theo":
   POST /api/ai/goi-y-buoc-tiep
   Input: sanPhamId, trangThaiHienTai
   Hiển thị 1-2 câu ngắn gọn
