# FlowOS ATK

Hệ thống quản lý dự án ra mắt sản phẩm ATK

**Stack:** Express + TypeScript + Prisma + PostgreSQL + React + Vite + Tailwind CSS

**Tính năng:**
- 🔐 Phân quyền 4 cấp (Quản trị viên / Trưởng nhóm / Thành viên / Quan sát)
- 📋 Quản lý công việc với soft-delete & undo
- 🌊 Dòng chảy dự án (ReactFlow)
- 👥 Quản trị thành viên
- 🔔 Socket.io real-time
- 🔗 Kết nối Lark
